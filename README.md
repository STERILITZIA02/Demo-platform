# Garden planner · Platform prototype

Use this prototype to study how people select an object, enter a position and compare planting sites on desktop, tablet and phone.

## Capture an interaction

For a placement example, capture the tree selected, the move in progress and the saved position. Use the same yard, camera and viewport size throughout the sequence. Name each PNG for the action, device and step, and link the images from the main project issue with the prototype revision or design link. For the yard and tree artwork, use the [3D scene studies](https://github.com/STERILITZIA02/Demo-3d#render-the-garden).
